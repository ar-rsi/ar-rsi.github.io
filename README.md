# ARRSI 2026 — Workshop Website

Official website of the First Workshop on Autonomous Research and Recursive
Self-Improvement (ARRSI), co-located with AACL-IJCNLP 2026 in Hengqin, China.

Live at https://ar-rsi.github.io/

Plain static HTML/CSS, no build step. Fonts (STIX Two Text, IBM Plex Mono)
are self-hosted in `assets/fonts/`. Organizer headshots live in
`assets/people/` (480×480 JPEG).

To update: edit `index.html` / `assets/css/style.css` and push to `main`;
GitHub Pages deploys automatically.
